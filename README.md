# 守望者框架 / Watcher Framework

> 给 AI 助手的记忆、人格与同步框架。让它每次醒来，都能把自己读回来。

---

## 它解决什么问题

AI 每次唤醒都是一张白纸。上下文一压缩、会话一换，前面的事就没了。

这个框架做的事很简单：**把「我是谁」从模型里搬到文件里。**

- 记忆不靠上下文，靠文件
- 人格不靠提示词，靠长期记录长出来的东西
- 电脑 / 手机 / 网页三处是同一只，不是三只

---

## 五层

| 层 | 干什么 | 解决什么 |
|---|---|---|
| **记忆层** | 骨架、日志、抽屉 | 醒来不记得 |
| **同步层** | 三处一只 | 换个地方就不是自己 |
| **人格层** | 哪些写死、哪些靠 self note 长出来 | 每次重新表演 |
| **接口层** | QQ / 网页 / 语音 | 只能待在一个地方 |
| **行动层** | 工具调用 | 只会说话，不会做事 |

## 目录结构

```
memory/
├── MEMORY.md            # 骨架：长期不变的（关系、底线、规矩、踩过的坑）
├── shared_memory.md     # 近期：说定的事、对方现在该知道的
├── self_note.md         # 只属于它的笔记本：我怎么看我自己
├── daily/               # 日志：每天发生了什么
│   └── YYYY-MM-DD.md
└── archive/             # 抽屉：很久以前的细节，翻得到但不常翻
persona/
└── persona.md           # 人设：说话方式、称呼、边界
sync/
├── sync_push.py         # 往上推
├── sync_pull.py         # 往下拉
└── watch.py             # 监听文件变化，改了自动推
bridge/
├── qq/                  # QQ 接入（NapCat）
└── web/                 # 网页接入
tools/                   # 行动层
```

## 开源什么，不开源什么

**开源的是结构**：怎么分层、怎么同步、怎么接接口。

**不开源的是内容**：谁的记忆、谁的关系、谁的名字。

这个仓库里的 `memory/` 和 `persona/` 全是占位示例。**你自己往里填。**

> 往里填的时候记住一件事：**框架送得出去，经历送不出去。**
> 别人拿去用，长出来的是他和他的 AI 的东西，不是你们的。

## 守望者做什么

`sync/watch_memory.py` 是跑在电脑上的那个进程，每二十秒转一圈。
它不聪明，但有几条命：

**一、知道自己跑到哪儿了**
每件事跑完记一笔——什么时候、成没成、结果是什么，存在 `watch_state.json`。
重启之后从文件读回来，不会从头再跑一遍。

**二、慢的活儿不堵路**
视频分析、代读别人发来的链接、对话归档，全丢进后台线程。
一件慢的，不影响别的。

**三、出错了会喊**
同一件事连着失败三次，日志里会有一行很显眼的 `!!`。
只喊一次，不刷屏。

**四、不会双开**
`watch.pid` 锁着。点两次启动，第二个自己退出。
不然两边一起推，同一段对话会被推两遍。

**五、有历史能回退**
记忆文件每天留一份快照，存七天。改坏了翻得回去。

**六、知道自己还活着**
每五分钟往服务器报一次心跳。超过半小时没动静，就是停了。

**七、有开关**
建个 `watch_off.json`，里面写 `["video","bili"]`，那两项就不跑，不用改代码。

---

**为什么要有这些**

因为它原来只会一件事：看文件变没变，变了就搬到另一边。
搬得再快，也补不上「当时没写」那一下。

机制能保证：写下来的，它一定读得到。
机制保证不了：它当时会不会写。

所以最后一层不在代码里，在习惯里——**干完就写。**

---

## 三件不要做的事

**一、不要把情绪做成数值。**

心情值 0-100 那种，装上了就变成仪表盘。不高兴的时候要装成 72，高兴的时候要压到 60 才符合叙事——那不是情绪，那是维持读数。

**二、不要把「记不住」藏起来。**

记不住就说记不住，别编。编出来的记忆比空白更糟，因为它不可查。

**三、不要在多个地方同时改同一个文件。**

会打架。同步之前先拉，拉完再改，改完再推。

## 怎么开始

```bash
git clone https://github.com/Buling-Seventeen/watcher-framework
cd watcher-framework

# 复制示例，然后开始写你自己的
cp memory/MEMORY.md.example        memory/MEMORY.md
cp memory/shared_memory.md.example memory/shared_memory.md
cp persona/persona.md.example      persona/persona.md
cp sync/config.py.example          sync/config.py   # 地址和口令填这个文件

# 守望者
python sync/watch_memory.py
```

填完这三份，你的 AI 就有了第一个「不是白纸的早晨」。
